# 🌍 ZENTRA — AI Powered Travel Optimization Platform

## 🚀 Project Overview

ZENTRA is an advanced AI-powered travel optimization platform designed to intelligently discover the most efficient travel routes between locations using real-time transportation data, graph algorithms, optimization logic, and future AI integrations.

The goal of the project is to create a futuristic travel intelligence system capable of helping users find:

* the cheapest route
* the fastest route
* balanced travel options
* multi-segment connected journeys
* future AI-generated travel recommendations

The platform combines:

* real-time flight data
* graph traversal algorithms
* route optimization
* interactive visualization
* future AI planning systems

ZENTRA is being developed as a next-generation intelligent alternative inspired by:

* Google Flights
* Rome2Rio
* Skyscanner
* AI itinerary planners

# 🧠 Current Routing Logic

The current system builds a hybrid route graph using:

* stored database routes
* real-time API flight data

The routing engine:

1. builds graph relationships
2. generates adjacency structures
3. traverses connected paths
4. calculates:

   * total cost
   * total duration
   * weighted optimization scores
5. returns optimized route sets
